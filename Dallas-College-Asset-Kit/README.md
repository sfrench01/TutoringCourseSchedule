# Dallas College asset kit

Your reusable working folder for flyers and presentations. Checked 2026-09-23.
This is a personal reference kit assembled from public Dallas College assets and your deck. It is not an official brand manual or marketing approval.

They are static font files for convenient desktop use. Font revisions can change line breaks slightly, so review text wrapping when moving between apps.

## Illustrator

1. Unzip the kit. Install the included TTF files using your operating system's font installer, then reopen Illustrator if needed.
2. For screen work, open `Dallas-College-RGB.ase` through the Swatches panel's swatch library controls. For print, use the separate CMYK file and the print profile your printer requests.
3. Open or place the official EPS artwork from the `VECTOR` folders. The Master Mark SVGs are another vector option. Keep the logo's width and height linked.
4. Use PNG files for quick placement. The web PNGs are small, so use EPS or SVG for large print work.

## Figma

1. Install the fonts before opening the editable reference page. The desktop app can use local fonts. In a browser, use Figma's font installer if local fonts are unavailable.
2. Drag the Master Mark SVGs and `color-swatches.svg` into a design file. The other logo variants are supplied as original PNGs and EPS files. Use PNG in Figma, or export an SVG from the official EPS in Illustrator while preserving the artwork.
3. Create local color styles or variables with the three published HEX values. The included SVG swatches are editable shapes. The CSV, CSS and JSON are copyable references, not an automatic Figma library or native variable-import package.
4. Set headings to Montserrat ExtraBold and body text to Montserrat Regular. Keep an editable text copy before outlining anything for handoff.

## PowerPoint and other tools

Install the TTFs, restart the app, and choose the matching weights. Insert the transparent PNG or SVG logo without stretching it. The red pattern is a raster asset, 1213 x 2250 pixels. Keep its proportions and avoid upscaling for large print. Use it as a border or background like the original deck, not as a substitute for the complete logo.

No personal photos are in this reusable brand kit. Your presentation and source photos remain unchanged. No AI-generated artwork is included. The official blank PowerPoint templates and campus logo packs are linked in Sources rather than duplicated here.

## Logo use

Keep the downloaded artwork intact. Don't rotate, stretch, recolor or add visual effects. Choose an uncluttered background and follow the college's contrast guidance. White logos belong on official blue, black or dark grey. Black logos belong on white.

For college marketing flyers and posters, use the Master or Vertical mark and follow Marketing & Communications approval requirements. The D Mark is supplied as the official symbol, not as a replacement for that full-mark requirement. Keep the D and star together as supplied.

Read the current [logo guidance](https://www.dallascollege.edu/about/style/college-logos/) before publishing. The included logo files retain their original names, formats and contents. EPS and PNG previews can differ slightly because of color management. Do not recolor logos to compensate.

## Sources and file integrity

`05-Sources/SOURCES.md` has clickable source links, including software help. `asset-manifest.json` records each asset's origin, size and SHA-256 hash. The manifest covers the kit's files except itself. This kit does not install fonts or change any app settings for you.
